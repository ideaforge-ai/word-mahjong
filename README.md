# Word Mahjong 单词麻将

一个结合麻将摸打机制与英语单词学习的网页小游戏。

## 功能特点

- 四人麻将式摸牌、打牌流程
- 英文字母牌组成单词
- 支持基础、进阶、高阶、学术、挑战五种难度
- 支持查词
- 支持胡牌检测
- 支持复习词表
- 支持浏览器本地保存复习词

## 在线体验

https://ideaforge-ai.github.io/word-mahjong/

## 本地运行

直接双击 index.html，或使用 VS Code Live Server 打开。
